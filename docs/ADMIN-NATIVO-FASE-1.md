# PA Safra — Admin nativo — Fase 1

Este arquivo marca a abertura da vertente de administração nativa do PA Safra.

Escopo inicial: painel próprio em `/admin`, edição controlada de página inicial e palestras, pré-visualização antes da publicação e API segura via Cloudflare Pages Functions.

A escrita permanecerá bloqueada até a configuração explícita de autenticação e secrets no Cloudflare.
